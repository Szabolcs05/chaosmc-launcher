# ChaosMC Launcher

A ChaosMC magyar nyelvű Minecraft Java launchere Windows x64 rendszerre.

[Legújabb kiadás és telepítő](https://github.com/Szabolcs05/chaosmc-launcher/releases/latest) · [ChaosMC weboldal](https://chaosmc.hu/)

Fabulously Optimized, Vanilla és OptiFine profilok; automatikus Java- és játéktelepítés; skin-profilképek; saját Fabric-modok kezelése. Minecraft: 1.21.11, 26.2 és 26.3, az elérhető csomagok szerint.

Az új launcher a beépített nyilvános kulccsal ellenőrzött frissítéseket automatikusan letölti. 1.0.1 vagy korábbi változatról egyszer kézzel kell telepíteni az új kiadást. A kiadási privát kulcs nem része ennek a tárhelynek.

A Microsoft-belépés még nincs aktiválva. Saját jóváhagyott Microsoft-alkalmazás szükséges; az offline profilok használhatók. A Windows-telepítő jelenleg nem Authenticode-aláírt.

Ez nem hivatalos Minecraft-termék; nem áll kapcsolatban a Mojanggal vagy a Microsofttal.
